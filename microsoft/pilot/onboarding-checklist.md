# Paid Pilot Onboarding Checklist

Use this checklist for the first 3 to 5 paid design-partner pilots.

## Commercial Setup

- [ ] Confirm pilot sponsor and technical owner.
- [ ] Confirm business problem and target asset/system.
- [ ] Agree pilot scope: RCA, FRACAS, bad actor analysis, PM optimization, or
      executive brief.
- [ ] Agree pilot fee, payment method, and start date.
- [ ] Confirm data permission and confidentiality terms.
- [ ] Confirm whether customer name/logo can be used after success.

## Technical Setup

- [ ] Create SyncAI tenant.
- [ ] Create pilot users and roles.
- [ ] Configure Microsoft Entra sign-in if required.
- [ ] Confirm Teams/M365 tenant admin contact.
- [ ] Install private Teams app or publish Foundry agent to pilot scope.
- [ ] Configure document/source access.
- [ ] Confirm data retention and deletion expectations.

## Data Intake

- [ ] Asset register or functional location export.
- [ ] Work-order export for target time period.
- [ ] Downtime or production loss log.
- [ ] Failure codes / cause codes.
- [ ] PM task list for target assets.
- [ ] Existing RCA / FMEA / strategy documents.
- [ ] Relevant site standards or maintenance procedures.
- [ ] OEM manual excerpts if customer has rights to use them.

## First Analysis Pack

- [ ] Data quality assessment.
- [ ] Bad actor Pareto.
- [ ] MTBF / MTTR / availability calculations.
- [ ] Evidence gap list.
- [ ] RCA starter pack or FRACAS case.
- [ ] Corrective action register.
- [ ] Executive summary.

## Governance

- [ ] Identify approval owner for safety-critical recommendations.
- [ ] Identify owner for PM interval changes.
- [ ] Identify owner for OEM-limit or operating-envelope changes.
- [ ] Capture assumptions and confidence for each recommendation.
- [ ] Capture consequence of being wrong.
- [ ] Capture validation method and due date.

## Exit Criteria

- [ ] Customer confirms the analysis is useful.
- [ ] Customer identifies at least one high-value reliability opportunity.
- [ ] Customer agrees next paid step: expanded pilot, implementation, or
      subscription.
- [ ] SyncAI captures testimonial, case study permission, or quantified outcome
      target if allowed.
