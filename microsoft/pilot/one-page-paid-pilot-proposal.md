# SyncAI Reliability Data-To-Decision Pilot

## One-Page Proposal

SyncAI helps maintenance and reliability teams turn exported work-order, asset,
failure-history, PM, inspection, and reliability documents into a governed
engineering decision package.

This pilot is intentionally bounded. It proves value from one asset class,
system, site area, or chronic repeat-failure problem before any enterprise
integration.

## Best Fit

Use this pilot when the customer has one or more of these problems:

- repeat failures or bad actors
- weak failure/cause/remedy coding
- unclear PM value or PM interval basis
- manual reliability reporting
- incomplete asset context
- slow RCA / FRACAS setup
- messy SAP, Maximo, or CMMS exports
- maintenance leaders asking for a practical reliability priority list

## Scope

Duration: `14 days`

Pilot fee: `CAD $7,500`

Data boundary:

- one asset class, system, site area, or chronic problem
- exported or de-identified data only
- no live CMMS writeback required
- no production-system integration required
- no safety-critical implementation approval by SyncAI

## Customer Provides

Minimum useful package:

- 12-24 months of work orders or notifications
- asset register or tag list for the selected area/system
- current PM/task list if available
- relevant RCA, FMEA, inspection, condition-monitoring, or OEM excerpts if
  approved for use

The customer can de-identify asset names, people, vendors, costs, and site
details. Keep stable asset aliases, dates or month/year, descriptions, work
types, downtime, and repair duration where possible.

## SyncAI Delivers

The pilot produces a review-ready decision package:

- data quality assessment
- bad actor Pareto
- MTBF / MTTR / availability where data supports it
- reliability-ready asset onboarding profile
- RCA / FRACAS starter pack for the top issue
- draft failure-mode library or FMEA-lite
- PM opportunity list
- recommendation register with evidence, assumptions, confidence, approval
  needs, and consequence of being wrong
- executive reliability brief
- 30-minute findings review

## Decision Boundary

SyncAI is engineering decision support. It does not replace customer engineering,
operations, HSE, OEM, regulatory, or management approval.

High-risk recommendations require qualified customer review before execution,
including:

- PM interval changes
- PM task deletion
- run-to-failure decisions
- operating-envelope changes
- safety, environmental, regulatory, or production-critical decisions
- OEM limit changes

## Success Criteria

The pilot is successful if the customer receives at least three of these:

- credible bad actor list
- quantified data quality gap list
- one reliability-ready asset profile
- one RCA / FRACAS starter pack
- one PM optimization opportunity list
- one executive reliability brief
- one recommendation worth investigating or implementing
