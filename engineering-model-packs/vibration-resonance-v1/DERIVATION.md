# Derivation

For shaft speed \(n\) in revolutions per minute:

\[ f_s = \frac{n}{60} \]

For a declared forcing order \(o\):

\[ f_f = o f_s \]

For the bounded single-degree-of-freedom approximation with modal stiffness \(k\) and modal mass \(m\):

\[ f_n = \frac{1}{2\pi}\sqrt{\frac{k}{m}} \]

Each expression reduces to inverse seconds. The percentage separation between a measured peak \(f_p\) and reference \(f_r\) is:

\[ \Delta_f = 100\frac{|f_p-f_r|}{f_r} \]

SyncAI will not interpret \(\Delta_f\) without a site- or authority-approved tolerance linked as evidence.
