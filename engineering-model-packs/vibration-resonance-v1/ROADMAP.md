# Model promotion roadmap

1. `DRAFT` — schema, derivation, applicability, and verification contract captured. Current state.
2. `DERIVED` — derivation reviewed for internal consistency.
3. `VERIFIED` — independent deterministic checks passed.
4. `BENCH_VALIDATED` — controlled reference case bound as evidence.
5. `FIELD_VALIDATED` — site modal confirmation bound as evidence.
6. `ENGINEERING_APPROVED` — independent reviewer with vibration/rotordynamics competence accepts the stated use.
7. `PRODUCTION_ELIGIBLE` — no blocking verification debt and all production evidence present.

Any changed assumption, dependency, configuration, failed regression, expired evidence, or material field bias moves the version to `REVALIDATION_REQUIRED`. Superseded or unsafe versions are `RETIRED` without rewriting their recorded runs.
