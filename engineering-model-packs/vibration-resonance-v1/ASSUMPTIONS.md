# Assumptions

- The supplied mass and stiffness represent the mode being screened.
- RPM and vibration spectrum refer to the same stable operating window.
- The installed configuration matches the evidenced as-maintained baseline.
- The scalar model is used only as a first screen; mode shape, directionality, damping response, nonlinear supports, rub, and transient excitation require specialist analysis.
- No default frequency-match tolerance or operating limit is embedded.
