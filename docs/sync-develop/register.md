## Standing constraints (register-visible, binding on every row)

1. **Provenance.** `GateRequirement.source_authority` (LAW → REGULATION → CORPORATE_STANDARD → PROJECT_FRAMEWORK → CONTRACT → INDUSTRY_GUIDANCE → BEST_PRACTICE → AI_SUGGESTION) and `Evidence.provenance` (MEASURED … AI_INFERENCE) are enforced tiers, not labels. Public-Suncor-derived ADEM detail enters only as INDUSTRY_GUIDANCE/INFERRED — never as an authoritative corporate requirement. An AI inference never silently becomes verified evidence; tier promotion is an authorized-human act rejected otherwise at the persistence boundary. We do not market as "we digitized ADEM."
2. **Deterministic boundary (spec §70).** The LLM never determines: **gate passed · risk accepted · regulation satisfied · safety barrier adequate · project sanctioned · equipment safe to start · contract legally compliant.** Rules engines, validated calculations, and authorized humans only — enforced the way this repository already enforces them (BEFORE-triggers raising `check_violation`, SECURITY DEFINER RPCs checking authority, restrictive RLS). The LLM explains, detects, prepares. Every new D-family object ships with its prohibition enforcement on day one.
3. **No fabricated numbers.** Every calculation (§45–§55) refuses on insufficient input and carries its basis/sample count. A gate readiness of 97% is BLOCKED by one failed mandatory item. No baseline → no CPI. No approved benefit baseline → no Value Realization percentage.
4. **Reachable means done.** ✅ requires the full chain a customer can walk. Schema-only, demo-seed-only, and zero-caller RPCs are 🟡 by definition — this repository's own demotion history (74 rows, 2026-08-26) is the reason this rule exists.
5. **Extend, never parallel-track.** Every row names its canonical home in [overlap-map.md](overlap-map.md). One asset hierarchy, one evidence model, one decision store, one assumption family, one constraint model, one learning store, one audit ledger (AGENTS.md invariants 1–3, 8).
