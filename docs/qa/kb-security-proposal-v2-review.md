The source-aware policy changes ordinary authenticated reads. Authorized human inspection is an intentional exception; **do not claim quarantined text never leaves the database**. Service-role callers remain privileged infrastructure and may bypass RLS; application AI retrieval must use the governed RPCs. The proposal preserves auth.uid-first tenant scoping, claim-type restrictions and approved/non-superseded source filters.

The source-write trigger rescans an entire source for each changed row. Review transaction order and benchmark large batch ingest before accepting this design; do not infer production performance or concurrency correctness from sequential fixtures. MFA review binds an exact content revision, not engineering truth or operational authority. New case evidence mapping, atomic case updates and changed-source decision invalidation are still separate implementation work.
