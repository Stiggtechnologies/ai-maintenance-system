## Recommended Execution

1. Use the existing GPT to sell a paid design-partner pilot.
2. Recreate the GPT as a Microsoft Foundry prompt agent.
3. Publish the Foundry agent to pilot users in Microsoft 365 Copilot / Teams.
4. Wire SyncAI tool actions for deterministic calculations and workflow outputs.
5. Use the Teams app scaffold for richer tab, bot, file, and card workflows.
6. Use the AppSource draft once pilot proof and compliance assets are ready.
