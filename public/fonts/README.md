# Public journey fonts

Archivo (variable, Latin), IBM Plex Sans (regular, Latin), and IBM Plex Mono
(regular and medium, Latin) match the fonts observed on the approved SyncAI
marketing site. They are served locally so the application does not contact a
font CDN at runtime. Their upstream SIL Open Font License texts are included.

Upstream: https://github.com/google/fonts/tree/main/ofl/archivo,
https://github.com/google/fonts/tree/main/ofl/ibmplexsans,
https://github.com/google/fonts/tree/main/ofl/ibmplexmono.
